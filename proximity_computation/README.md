# proximity_computation

Computes network proximity scores between aging hallmark gene sets and age-related disease genes based on the Human PPI network, using "netmedpy.screening()".

------------------------------------------------------------------------------------------------------------------

## Contents
```
proximity_computation/                        
├── input/
│   ├── aging_hallmark_consensus.csv           # Aging hallmark gene sets
│   ├── disease_associated_gene.csv            # Disease–gene associations
│   ├── Human_PPI.pkl                          # Human PPI network
│   └── shortest_path_distances_Human_PPI.pkl  # Precomputed distance matrix (~3 GB)
├── src/
│   └── proximity_computation.py
└── output/
    └── proximity_<Disease>_vs_Aging.tsv       # One file per disease
```

> "shortest_path_distances_Human_PPI.pkl" is generated by "precompute_PPI_distances" and must be present before running this script.

------------------------------------------------------------------------------------------------------------

## What it does

1. Loads the Human PPI network and restricts it to its Largest Connected Component (LCC)
2. Loads the precomputed all-pair shortest path distance matrix
3. Parses aging hallmark gene sets from [aging_hallmark_consensus.csv](./input/aging_hallmark_consensus.csv), grouped by hallmark
4. Parses disease–gene associations from [disease_associated_gene.csv](./input/disease_associated_gene.csv) (supports multiple diseases per gene via "|" separator)
5. Filters all gene sets to only include nodes present in the PPI LCC
6. For each disease, runs "netmedpy.screening()" against all aging hallmarks
7. Saves one TSV output file per disease to "output/"

-----------------------------------------------------------------------------------------------------------------

## Usage

Bash Command

```bash
cd src
python proximity_computation.py
```

Key parameters (edit inside the script)

| Parameter | Default | Description |
|-----------|---------|-------------|
| "n_procs" | "5" | Number of parallel CPU processes |
| "null_model" | "log_binning" | Null model for z-score normalization |
| "symmetric" | "False" | Whether to compute proximity symmetrically |
| "n_iter" | "1000" | Number of null model iterations |
| "properties_to_compute" | ["raw_amspl", "z_score", "p_value_single_tail"] | Metrics to compute |

## Output

One ".tsv" file per disease in "output/", named "proximity_<Disease>_vs_Aging.tsv".

Each file contains one row per aging hallmark:

| Column | Description |
|--------|-------------|
| "Aging_Hallmark" | Name of the aging hallmark |
| "raw_amspl" | Raw average minimum shortest path length |
| "z_score" | z-score relative to null model |
| "p_value_single_tail" | One-tailed p-value |
